# SumUp Homebrew Tap

</div>

Public [Homebrew](https://brew.sh) tap for the SumUp CLI.

## SumUp CLI

This tap publishes the sumup cask for the [SumUp CLI](https://github.com/sumup/sumup-cli).

```sh
brew install sumup/cli/sumup
```
